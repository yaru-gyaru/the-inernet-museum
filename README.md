# The Internet Museum

Интерактивный веб-музей об интернете 1990-х, 2000-х и 2010-х годов в киберпанк-стиле. Каждая эпоха меняет цветовую палитру, фоновые элементы и экран компьютера. Посетитель взаимодействует с реконструкциями браузера, форума и социальной ленты, читает короткие истории и хронологию событий.

Короткий маршрут предлагает найти одного человека и написать ему тремя способами: через гостевую книгу в 1994-м, форум в 2003-м и личное сообщение в 2012-м. Карта сети показывает продвижение по выбранной эпохе. Сообщения остаются только в интерфейсе и никуда не отправляются. Рядом с каждой реконструкцией есть ссылка на подлинный веб-артефакт.

## Запуск

```bash
npm install
npm run dev
```

Для сборки: `npm run build`. Результат находится в `dist/`.

Проект использует React, Vite, CSS и Canvas. Звук включается отдельной кнопкой. При системной настройке уменьшения анимации движение интерфейса отключается.
