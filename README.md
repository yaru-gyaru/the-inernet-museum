# The Internet Museum

Интерактивный веб-музей об интернете 1990-х, 2000-х и 2010-х годов. Посетитель переключает эпохи, взаимодействует с реконструкциями браузера, форума и социальной ленты, читает короткие исторические заметки и отвечает на вопросы викторины.

## Запуск

```bash
npm install
npm run dev
```

Для сборки: `npm run build`. Результат находится в `dist/`.

Проект использует React, Vite, CSS и Canvas. Звук включается отдельной кнопкой. Ссылки «Заглянуть в архив» ведут на внешние исторические ресурсы.
